### Blocking issues

1.  **`bin/spine-batch.mjs` (in `parseBatchArgs` and `runSpineBatch`)** — The validation for `--batch` IDs is bypassed when the flag is provided without a value. `parseBatchArgs` returns `null` for the `batchId` in this case, and the validation guard `if (parsed.batchId != null)` is not triggered. Downstream commands like `dismissBatch` then silently default to operating on the currently active batch, which is a dangerous and unexpected behavior. The argument parser must be modified to detect when `--batch` is present without a value and either fail immediately or provide a value (like an empty string) that the existing validator will reject.
