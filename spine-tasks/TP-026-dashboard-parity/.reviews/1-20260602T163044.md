## Findings

### Minor (non-blocking)

1. **CLI JSON not exercised directly** — PROMPT wording says “CLI JSON === dashboard snapshot.” The test compares `reconcileBatch` to `buildDashboardSnapshot`, which is correct structurally (`runSpineStatus({ json: true })` emits `reconcileBatch` output). A thin test calling `runSpineStatus` and comparing the parsed JSON subset would close the literal AC gap and guard against future CLI shaping.

2. **`failed` diagnosis enum** — Matrix lists `failed`; the only “failed” case asserts `needs_retry` because `hasFailedTasks` wins in `deriveDiagnosis`. Acceptable for parity; add a dedicated fixture only if a reachable `diagnosis: "failed"` path matters for operators.

3. **Overlap with `snapshot.test.mjs`** — Idle parity duplicates the existing idle test; acceptable for a dedicated parity module.

4. **Untracked file** — `tests/dashboard/parity.test.mjs` does not appear in `git diff --name-only`; ensure it is staged before commit.
