### Summary

Step 3 closes the operator-facing loop for FR-STALL-01.2 / 01.4 / 01.5. All terminal worker paths in `worker-host.mjs` now return bounded, redacted output through `finalizeWorkerOutput` (`buildWorkerFailureResult` for abort/stall, direct call on normal exit). ### What looks good

- **Minimal engine touch.** Reusing the existing `...workerResult` spread keeps journal payload wiring in one place and avoids duplicating failure emission logic.
- **Evidence collector shape.** `collectWorkerOutputEvidenceRefs` is filesystem-driven, sorted, and vault-relative — it references logs that exist on disk without depending on test/build gate command success.
- **Diagnose path citation.** `recordStallKilled` stores `logRef ?? logPath` (vault-relative); `summarizeJournalEvent` appends `→ ${payload.logPath}`; tests assert both hint type and summary contain `worker-output-SP-056.log`.
- **Failure builder consistency.** `buildWorkerFailureResult` centralizes abort and stall branches; stall passes `stallDeadline` and `signals` only where needed.

None blocking.

### Non-blocking notes

- **Untracked dependencies.** `src/batch/worker-output.mjs` and `tests/batch/stall-output.test.mjs` are required for this step but absent from `git diff --name-only` (`??` in status). Stage both before the Step 3/4 commit.
- **Journal payload cap vs capture max.** `captureWorkerOutputTail` defaults to 262 KiB while `capPayloadSize` limits any journal event to 32 KiB. Very large captured tails can collapse the entire `task.failed` payload into `_truncated` / `preview` even when the on-disk log is correct. Consider field-wise capping or aligning sizes in a follow-up.
- **Diagnosis hint ordering.** `extractJournalDiagnosisHints` lists `task.failed` before `lane.stall_killed`; the first hint may show only `classification` while the log path appears on the second hint. Acceptable for stall repro; optional polish: summarize `workerOutputLogRef` on `task.failed`.
- **Absolute path in journal.** Spreading full `workerResult` also writes `workerOutputLogPath` (absolute filesystem path) into `task.failed`. Prefer omitting absolute paths from journal payloads if tightening later.
- **Step boundary.** Stub hang hooks in `bin/spine-worker-runner.mjs` and broad `stall-output.test.mjs` overlap Step 4 in PROMPT; acceptable on one branch, but split commits if strict step hygiene matters.
